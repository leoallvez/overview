# Claude Code Guide - Overview Project

This project follows a specific architecture and workflow designed for AI agents.

## Mandatory Guidelines
Before starting any work, you **MUST** read and adhere to the guidelines defined in [AGENTS.md](file:///home/leoallvez/Source/overview/AGENTS.md).

## Summary of Workflow
1.  **Context:** Understand the multi-module structure (app, domain, data, presentation).
2.  **Skills:** Use specialized skills in `.agents/skills/` for all implementations.
3.  **Planning:** Always present an implementation plan for approval.
4.  **Verification:** Ensure all tests pass before completing a task.
5.  **Commits:** Use the `git-standardizer` pattern for commit messages.

Refer to [AGENTS.md](file:///home/leoallvez/Source/overview/AGENTS.md) for the full specification and mandatory rules.
